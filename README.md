# ETERNAL Launcher

Лаунчер українського RP-сервера ETERNAL.

## Встановлення

1. Відкрийте розділ [Releases](https://github.com/DenysNikiforov/eternal-launcher-releases/releases/latest) і завантажте `ETERNAL-Launcher-Setup-x.x.x.exe`.
2. Запустіть файл. Якщо Windows покаже вікно «Windows захистила ваш ПК» - натисніть «Докладніше» → «Однаково запустити».
3. Для гри потрібні встановлені GTA V і [FiveM](https://fivem.net/).

Лаунчер оновлюється сам - нові версії встановлювати вручну не потрібно.
